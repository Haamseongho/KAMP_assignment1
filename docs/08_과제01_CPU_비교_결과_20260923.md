# KAMP 과제① CPU 비교 결과 — 2026-09-23

**판정:** 7개 CPU 후보 × 3 seed × 고정 개발 5-fold OOF 완료. 전체 AP 평균 기준 기존 로지스틱 기준선 0.1154가 가장 높다. GPU 실행은 과제④ 결과 ZIP 회수 전 중단. 숫자 라벨 1의 실제 불량 의미, 원시 시계열, 독립 전방검증은 미확인.

개발 데이터는 1,913행·숫자 양성 33행·동일특성 그룹 957개다. 로지스틱 seed 20260922의 CN7 AP는 0.2863/양성 13개, RG3 AP는 0.0231/양성 20개다. RG3의 양성 비율은 0.0211이므로 로지스틱 성능은 무작위 기준에 가까우며 **현장 자동 의사결정 불가**다. 로지스틱의 seed SD 0은 고정 seed의 결정적 학습을 3회 동일 재실행했기 때문이지 통계적 안정성을 입증하지 않는다. XGBoost regularized는 단일 seed 20260923에서 전체 AP 0.1201로 로지스틱을 넘었으나 seed 평균은 낮고 표준편차 0.0206이므로 우위가 재현되지 않았다.

고정 fold별 로지스틱 AP는 seed 20260922 기준 0.0261–0.3208이며 fold당 양성은 6–7개다. 조건부 오류에서는 로지스틱의 fold·설비별 상위10% 할당 기준 RG3 숫자 양성 20개 중 18개가 상위10% 밖에 있었다. 이는 전체 OOF 점수에서 설비별 한 번에 상위10%를 정한 결과(1/20 포착)와 할당 정의가 달라 직접 동일시하지 않는다. 조건표는 `condition_slices.csv`; 공정 변수 중앙값은 항상 해당 fold 학습 데이터에서만 계산했다.

`brier_unadjusted`와 log-loss는 class weighting 적용 원점수의 진단치이며 검증된 확률이 아니다. 숫자 라벨 1의 결함 의미, 공급자 전처리/스케일러, 시간·제품·배치 단위 독립성도 미확인이다. 따라서 이번 결과는 **후보 선택용 개발 OOF**이지 향후 생산·대회 일반화 성능의 증거가 아니다. 기존 480행 holdout은 과거 분석에 사용되어 이번 튜닝 평가에서 제외했다.
