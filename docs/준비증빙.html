KAMP 2026 · 준비 증빙 03 / 03

결과 파일 검사 틀

공식 제출 형식 공개 후 값을 채워 실행하는 CSV 검사기

검사 틀 준비 완료 · 제출 규격 확정 대기
검사 항목오류 조건 / 확인 방식
열 스키마공식 제출 예시 또는 설정의 열 이름과 순서가 다르면 실패
행 수참조 파일 또는 공식 예상 행 수와 다르면 실패
ID빈 ID, 중복 ID, 참조 파일과 다른 행 순서면 실패
예측값비어 있는 값, 지정 수치열의 비수치·NaN·무한대면 실패
허용 레이블공식 허용 목록을 설정한 경우 그 밖의 값이면 실패
안전장치제출 예시/열/행/예측열 설정 전에는 검사를 완료로 간주하지 않음

공개 후 실행 명령

cp config/task.template.json config/task.json
# 공식 제출 예시·열·행 수·예측열을 task.json에 확인해 입력
python kamp_prep.py check-output outputs/실제_결과.csv \
  --config config/task.json
현재는 실제 과제의 결과 파일이나 제출 규격이 없으므로 검사 결과를 PASS라고 표시하지 않습니다. 공식 형식이 CSV가 아니면 이 검사기를 그대로 사용하지 않습니다.
