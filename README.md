2026-09-22 실제 공개 과제와 `사출성형기 AI 데이터셋` 네 CSV를 사용한 CPU 전용 분석 시제품. 공식 과제는 현재의 공정 종료 후 품질검사를 배경으로 **최종검사 이전 이상 예측 및 검사 우선순위 결정**을 요구한다. 공정 종료 전 예측까지 요구한다고 단정하지 않으며, 현 CSV의 변수별 사용 가능 시각도 미확인이다. 준비 단계의 가상 스키마가 아니라 실제 2,393개 라벨 행과 71,180개 비라벨 행을 검증·분석했다.

가장 중요한 결론: 같은 센서값에 상반된 라벨이 있는 36그룹, RG3의 약한 검증 성능, 현재 CSV의 미확정 0/1 의미 때문에 **모든 제품의 기존 검사를 유지**한다. 점수와 순위는 오프라인 분석값이며 검사를 생략하거나 설비를 자동 제어하는 근거가 아니다. 상세 수치·실패 조건·평가 양식 제1~6장 대응은 [검증 보고서](docs/03_사출성형_검증보고서.md), 라벨 근거의 충돌은 [검증 메모](docs/05_라벨_의미_검증.md)를 읽는다.

## 재현 명령

처음 실행하는 경우 프로젝트 최상단의 [로컬 실행·검증 가이드](로컬_실행_가이드.md)를 먼저 읽는다. 준비된 환경에서 `.venv-repro/bin/python run_local.py quick`으로 점검하고, `full`로 실행하면 기존 결과를 보존한 새 폴더에 단계별 로그와 분할 명세가 저장된다. 공유용 표 이미지는 `.venv-repro/bin/python export_result_tables.py`로 생성한다.

Python 3.12 환경에서 이 디렉터리의 원본 CSV 네 개를 유지한다. 현재 재현 환경은 `.venv-repro`이며 전체 버전 고정 목록은 `requirements-model-lock.txt`다. 환경을 새로 만들 때만 가이드의 설치 절차를 따른다.

```bash
cd /Users/hamseongho/Documents/ChatGPT/KAMP
.venv-repro/bin/python run_local.py quick
.venv-repro/bin/python run_local.py full
.venv-repro/bin/python export_result_tables.py
```

로컬에 이미 만들어진 결과는 `outputs/moldguard/`에 있다. 핵심 파일은 `data_audit.json`(데이터 검증), `experiment.json`(모델 비교·홀드아웃), `failure_analysis.json`(실패 조건·분포 이동), `unlabeled_priority.csv`(71,180행 검사 대기열), `reproducibility.json`(명령·해시·테스트 로그)이다. 원본과 행 단위 결과는 `.gitignore`에 따라 Git에 추가하지 않으며, 과제① 비교의 집계 결과만 예외로 공개한다.

## 코드와 이전 준비물

- `moldguard.py`: 원본 검증, 동일 관측값 그룹 분할, 기준선·비선형 모델 비교, 학습·추론, 결과 검증
- `analyze_moldguard.py`: 오류 유형, 설비별 지표, 인덱스 순서 스트레스, 비라벨 분포 이동, 그림·재현 로그
- `tests/test_moldguard.py`: 누수·모순 그룹·대기열·OOD 복귀·결과 파일 검사 테스트
- `kamp_prep.py`, `config/task.template.json`, `docs/운영절차.md`: 9/21 공개 **이전**에 작성한 일반 준비 도구와 체크리스트. 실제 과제의 모델 코드는 `moldguard.py`다. 이전 문서의 “데이터 미공개” 설명은 당시 기록이며 현재 상태가 아니다.

점수는 보정된 불량 확률이 아니다. 코드북·원시 단위·실제 시각·캐비티/제품 식별자가 도착하면 데이터 계약과 전방검증을 갱신해야 한다. 이 작업은 대회 사이트에 최종 결과를 제출하지 않는다.
